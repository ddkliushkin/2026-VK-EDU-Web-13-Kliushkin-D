# Voprosik — Сервис вопросов и ответов

Учебный проект в рамках курса Web-разработки VK Education. Платформа представляет собой сервис для обмена знаниями, где пользователи могут регистрироваться, настраивать профиль с аватаром, задавать вопросы, отвечать на них, использовать систему тегов, голосовать и отмечать правильные ответы.

**Разработчик:** Клюшкин Данила (группа Web-13)

## Структура проекта

```text
├── application/            # Настройки Django-проекта (settings.py, urls.py)
├── core/                   # Пользователи (профиль, формы авторизации/профиля, base-шаблон, статика и main.js)
├── questions/              # Q&A (модели, менеджеры, формы, админка, команда fill_db, вьюхи, AJAX, пагинация)
├── public/                 # Статическая верстка из ДЗ-1
├── manage.py               # Скрипт управления Django
├── requirements.txt        # Зависимости Python
├── Dockerfile              # Конфигурация Docker-образа
├── docker-compose.yml      # Запуск Django и PostgreSQL через Docker Compose
├── .env.example            # Пример переменных окружения
├── .gitignore              # Исключения для Git
└── README.md               # Документация проекта
```
