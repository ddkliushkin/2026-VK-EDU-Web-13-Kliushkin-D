# Voprosik — Сервис вопросов и ответов



Учебный проект в рамках курса Web-разработки VK Education. Платформа представляет собой сервис для обмена знаниями, где пользователи могут задавать вопросы, отвечать на них, использовать систему тегов и голосовать за лучшие публикации.



**Разработчик:** Клюшкин Данила (группа Web-13)



## Структура проекта

```text
├── public/                 # Директория с разметкой страниц
│   ├── static/             # Локальная статика
│   │   ├── css/            # Таблицы стилей (Bootstrap + style.css)
│   │   ├── js/             # Скрипты (Bootstrap bundle)
│   │   └── img/            # Графика, аватарки, favicon
│   ├── base.html           # Базовый каркас для наследования
│   ├── index.html          # Главная страница
│   ├── question.html       # Детальная страница вопроса с ответами
│   ├── ask.html            # Форма добавления нового вопроса
│   ├── login.html          # Форма входа в аккаунт
│   ├── signup.html         # Форма регистрации нового пользователя
│   └── profile.html        # Страница настроек профиля
├── .gitignore              # Исключения для Git
└── README.md               # Документация проекта
