# Voprosik — Сервис вопросов и ответов

Учебный проект в рамках курса Web-разработки VK Education. Платформа представляет собой сервис для обмена знаниями, где пользователи могут задавать вопросы, отвечать на них, использовать систему тегов и голосовать за лучшие публикации.

**Разработчик:** Клюшкин Данила (группа Web-13)

## Структура проекта

```text
├── application/            # Настройки Django-проекта (settings.py, urls.py)
├── core/                   # Приложение пользователей (login, signup, profile, base-шаблон, статика)
├── questions/              # Приложение вопросов и ответов (index, hot, tag, question, ask, пагинация)
├── public/                 # Статическая верстка из ДЗ-1
├── manage.py               # Скрипт управления Django
├── requirements.txt        # Зависимости Python
├── Dockerfile              # Конфигурация Docker-образа
├── docker-compose.yml      # Запуск проекта через Docker Compose
├── .env.example            # Пример переменных окружения
├── .gitignore              # Исключения для Git
└── README.md               # Документация проекта
